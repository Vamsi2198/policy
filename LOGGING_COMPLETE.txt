🔍 VIEWING LOGS
═══════════════════════════════════════════════════════════════════════════════

Using Python script:
  python src/view_snowflake_logs.py                    # All logs + summary
  python src/view_snowflake_logs.py --summary-only     # Statistics only
  python src/view_snowflake_logs.py --status FAILED --errors  # Debug failures
  python src/view_snowflake_logs.py --limit 10         # Last 10 queries

Using PowerShell (Windows):
  .\view_logs.ps1 summary          # Show statistics
  .\view_logs.ps1 failed -Errors   # Show failures with details
  .\view_logs.ps1 recent -Limit 5  # Last 5 queries
  .\view_logs.ps1 tail             # Watch real-time
  .\view_logs.ps1 help             # Show all options

Direct file access:
  cat snowflake_queries.log                            # View all
  tail -f snowflake_queries.log                        # Watch real-time
  grep -A 10 "FAILED" snowflake_queries.log           # Find failures
